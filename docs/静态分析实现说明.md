# 静态分析实现说明

论文主线使用 51job 社招文本构建静态 `city × job_family` 分析表。实现流程分为岗位级抽取、指标聚合和论文展示三个环节。

## 岗位级抽取

| 内容 | 位置 |
| --- | --- |
| 主输入 | `data/processed/51job/51job_social_jobs_clean_with_publish.csv` |
| 主脚本 | `src/analysis_static/a_extraction/build_51job_master_static.py` |
| 收口脚本 | `src/analysis_static/a_extraction/finalize_51job_master_static.py` |
| 主要输出 | `analysis/tables/extraction_outputs/` |

该环节完成城市标准化、岗位族标准化、技能任务抽取、GenAI 标签构造和质量报告。

## 指标聚合

| 输出 | 用途 |
| --- | --- |
| `panel_cg_model.csv` | 城市-岗位族模型输入 |
| `city_classification.csv` | 城市分组、排名和展示指标 |
| `paper_tables_csv/` | 正文表格的 CSV 版本 |

聚合后的表格支撑样本描述、暴露度测度、机制检验、异质性分析和稳健性检查。

## 论文展示

正文图形位于 `analysis/figures/`，正文表格位于 `analysis/tables/paper_tables_csv/`，Word 与 PDF 原稿位于 `analysis/manuscript/`。全量中间数据通过 `data-v1.0` Release 恢复。
