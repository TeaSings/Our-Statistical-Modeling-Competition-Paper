# NCSS 全量数据核验说明

本文记录 NCSS 全地区扩展样本的完整性核验。该样本是辅助数据和抓取脚本验证材料，不作为最终论文主样本。

## 核验对象

| 文件 | 角色 |
| --- | --- |
| `data/input/ncss/ncss_detail_urls_all_areas.csv` | 全国详情主种子 |
| `data/raw/ncss/manifests/ncss_detail_manifest_all_areas.jsonl` | 详情抓取 manifest |
| `data/raw/ncss/records/ncss_jobs_all_areas_raw.jsonl` | 详情解析原始记录 |
| `data/processed/ncss/ncss_jobs_all_areas_clean.csv` | 清洗后 NCSS 样本 |
| `data/processed/ncss/ncss_listings_all_areas_flat.csv` | 全国列表覆盖底表 |

## 样本链路

| 阶段 | 数量 |
| --- | ---: |
| 全国唯一职位种子 | 41407 |
| 有效详情解析 | 41400 |
| 清洗后职位 | 30985 |

`41407 -> 41400` 的差额来自源站不可恢复页面：

- 4 条详情页显示信息已删除。
- 3 条详情页可访问但正文节点为空。

这些异常属于源站状态，不再建议通过全量重跑解决。

## 使用方式

NCSS 数据在当前仓库中的作用是：

- 提供全国地区码和城市口径参考。
- 验证列表抓取、详情抓取、HTML 解析和清洗脚本。
- 作为招聘文本分析的辅助样本和可扩展来源。

最终论文主样本仍以 51job 社招数据为准。完整 NCSS 原始和中间文件应放在 GitHub Release 数据包中，不进入 Git 历史。
