# NCSS 数据流程说明

NCSS 数据在本项目中主要用于地区口径补充、抓取流程验证和辅助样本检查。最终论文主样本以 51job 社招数据为准。

## 数据来源

| 类型 | 位置 |
| --- | --- |
| 地区码和详情页种子 | `data/input/ncss/` |
| 原始抓取记录 | `data/raw/ncss/` |
| 清洗后岗位表 | `data/processed/ncss/` |
| 脚本 | `src/platforms/ncss/` |

## 流程

1. 使用地区码构造列表页和详情页抓取任务。
2. 采集列表页与详情页 HTML，并保存 manifest。
3. 解析岗位标题、单位、地区、发布时间和正文信息。
4. 输出清洗后的全国岗位表与查询汇总表。

## 使用边界

NCSS 清洗表不作为论文的主回归样本。它用于补充地区口径、验证招聘文本解析链路，并为后续扩展分析保留数据基础。完整 NCSS 原始记录和清洗表通过 `data-v1.0` Release 恢复。
