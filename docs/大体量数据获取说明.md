# 大体量数据获取说明

Git 仓库只保存论文、代码、图表、小型结果表和说明文档。原始抓取记录、全量清洗表和大体量中间表通过 GitHub Release 附件归档：

https://github.com/TeaSings/Our-Statistical-Modeling-Competition-Paper/releases/tag/data-v1.0

## 何时需要下载

- 只阅读论文、查看图表或检查正文表格：不需要下载数据包。
- 复现实证流程、重新生成抽取结果或检查全量样本：下载全部 zip 附件和 `checksums-sha256.txt`。
- 只检查单一来源数据：可按 `docs/数据Release清单.md` 选择对应附件。

## 恢复步骤

1. 下载需要的 zip 附件和 `checksums-sha256.txt`。
2. 在仓库根目录解压 zip，保留压缩包内的相对路径。
3. 确认关键文件恢复到 `data/raw/`、`data/processed/` 或 `analysis/` 的对应位置。
4. 安装依赖后运行 `src/` 中的脚本。

```powershell
python -m pip install -r requirements.txt
python src/analysis_static/a_extraction/build_51job_master_static.py
python src/analysis_static/a_extraction/finalize_51job_master_static.py
```

## 校验方式

Release 中提供 `checksums-sha256.txt`。下载后可用 SHA256 校验附件完整性，确保文件未损坏。

GitHub 普通仓库文件超过 100 MiB 会被阻断，因此本项目使用 Release 分发大体量数据。相关限制可参考 GitHub 文档：

- https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github
- https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases
