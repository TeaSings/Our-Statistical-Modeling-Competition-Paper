# 规则迭代说明

岗位族和技能任务规则经过多轮抽查后收束为当前版本。迭代目标是在提升覆盖率的同时保留低置信复核样本，避免把规则难以判断的岗位强行归类。

## 主要调整

- 增强销售、商务、运营、供应链、生产质量等高频岗位族规则。
- 对泛化标题引入搜索关键词、岗位标签和正文线索。
- 补充财务、策略、顾问、实验、仿真、应用支持等混合岗位规则。
- 增加中英文混合标题、缩写和技术词识别。

## 最终结果

| 指标 | 数量 |
| --- | ---: |
| 低置信岗位族记录 | 152398 |
| `其他/待定` 记录 | 85532 |
| 人工复核去重样本 | 107336 |

这些复核样本用于说明规则边界。它们不影响当前论文主表和正文结果的复现。
