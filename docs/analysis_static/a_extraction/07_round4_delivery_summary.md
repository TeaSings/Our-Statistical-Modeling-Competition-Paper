# 规则细化记录：Round 4

Round 4 是当前仓库保留的最终岗位族规则版本。它进一步处理泛化职能、跨部门岗位和部分英文/缩写表达，使 `city × job_family` 聚合更适合论文建模。

## 调整方向

- 继续压缩 `其他/待定` 和低置信岗位族。
- 对财务、策略、顾问、实验、仿真、应用支持等混合岗位增加规则。
- 对中文标题中的英文缩写和技术词进行补充识别。
- 保留人工复核表，作为规则边界说明。

## 后续扩展方向

后续如果继续提高覆盖率，优先方向是：

- 中英文混合标题和简称。
- 泛化管理、顾问、策略类岗位。
- 实验、应用、仿真、技术支持类岗位。
- 金融顾问和行业策略类岗位。

这些扩展可以降低待复核规模，但不影响当前论文主表和正文结果的复现。
