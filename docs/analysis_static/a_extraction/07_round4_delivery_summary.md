# 07 第四轮精修交付总结

## 本轮目标

- 在第三轮正式交付版的基础上，继续提升 `job_level_master_static.csv` 的可交付性。
- 本轮继续坚持两条原则：
  - 只使用 `51job` 社招主样本；
  - 不轻易新增岗位族口径，优先用“高频精确标题 + 高频 keyword_seed 强化”吃掉明显可判样本。

## 本轮主要精修内容

- 新增或强化了以下类型的岗位族规则：
  - 文职/行政：`文员`、`内勤文员`、`工程文员`、`助理文员`
  - 招聘/人力：`猎头顾问`
  - 软件：`嵌入式工程师`
  - 供应链/关务：`关务专员`、`关务`、`进出口专员`、`国际贸易专员`
  - 运营：`电商专员`、`营运经理`、`营运主管`、`营运专员`、`营运助理`
  - 产品/项目：`产品助理`、`项目总监`
  - 测试/质量：`测试技术员`、`SMT工程师`、`SMT技术员`、`品控主管`、`品控经理`、`计量工程师`、`化验员`、`TE工程师`、`失效分析工程师`
  - 客服/技术支持：`FAE工程师`、`FAE现场应用工程师`、`售后工程师`
  - 硬件/自动化：`电机工程师`、`自控工程师`
  - 机械：`机械产品工程师`、`制冷工程师`、`汽车内外饰设计工程师`、`结构助理工程师`
  - 蓝领操作：`组装工`、`锅炉工`、`油漆工`、`喷漆工`、`铆工`、`钣金工`、`缝纫工`、`样衣工`、`搬运工`
  - 服务：`收银员`、`厨工`、`消防监控员`、`消控员`、`咖啡师`
- 对多个“标题强、seed 弱或 seed 噪声较大”的岗位，提升了标题规则权重，使最终判定更依赖职位名本身，而不是被错误 seed 抢权重。
