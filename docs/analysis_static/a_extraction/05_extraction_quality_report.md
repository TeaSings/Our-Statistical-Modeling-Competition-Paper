# 抽取质量报告

本文汇总 51job 静态抽取链的最终质量指标。指标用于说明样本覆盖、标准化成功率和规则抽取有效性。

## 样本规模

| 指标 | 数值 |
| --- | ---: |
| job-level 样本 | 1111676 |
| 城市映射成功率 | 99.3672% |
| 省份映射成功率 | 99.9737% |
| 城市复核样本 | 7439 |
| 岗位族低置信样本 | 152398 |

## 抽取覆盖

| 指标 | 比例 |
| --- | ---: |
| 技能命中率 | 35.3918% |
| 任务命中率 | 40.9106% |
| GenAI 显性命中率 | 0.6945% |

最常见岗位族为 `销售/商务`。该结果符合 51job 社招样本中销售和商务类岗位占比较高的结构特征。
