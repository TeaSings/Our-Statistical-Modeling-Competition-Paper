# 规则细化记录：Round 3

Round 3 的目标是减少泛化岗位标题带来的低置信岗位族，并提升规则词典对常见业务岗位的覆盖。本文保留为规则演化说明，不再作为阶段交付日志。

## 调整方向

- 增强销售、商务、运营、供应链、生产质量等高频岗位族规则。
- 对泛化标题引入关键词和岗位标签辅助判断。
- 保留低置信样本，避免为了提高覆盖率而过度强行分类。
- 将规则变化同步到岗位族复核表，便于后续人工检查。

## 产出影响

Round 3 明显降低了低置信样本规模，但仍保留了一定比例的待复核记录。这个设计使论文中的岗位族统计更稳定，同时避免把规则难以判断的岗位误归入具体类别。
