# 文档目录

本目录说明论文从招聘文本到正文图表的主要流程，面向希望理解或复现本项目的读者。

| 路径 | 内容 |
| --- | --- |
| `中文数据来源与脚本说明.md` | 数据来源、脚本入口和复现路径 |
| `数据分析初步方法.md` | 分析单元、变量构造和解释边界 |
| `静态分析实现说明.md` | 51job 静态分析链路和主要输出 |
| `analysis_static/` | 城市标准化、岗位族标准化、规则词典和质量报告 |
| `NCSS数据流程说明.md` | NCSS 辅助数据的采集、清洗和用途 |
| `大体量数据获取说明.md` | GitHub Release 数据包的下载和恢复方式 |
| `数据Release清单.md` | Release 附件、恢复路径和校验信息 |

论文成品位于 `analysis/`，代码位于 `src/`。大体量原始和中间数据不进入 Git，完整复现时从 Release 数据包恢复。
