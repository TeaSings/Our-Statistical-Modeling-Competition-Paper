# NCSS 全地区扩展抓取流程

该流程把 NCSS 从少数城市样本扩展为全国地区码扫描。当前仓库保留配置、脚本和说明；大体量 HTML、manifest 和清洗表通过 Release 数据包恢复。

## 流程目标

1. 从 NCSS 列表页提取全部公开地区码。
2. 对全部地区码执行空关键词列表扫描。
3. 导出详情页种子并抓取详情 HTML。
4. 解析详情页并生成全国辅助招聘样本。

## 关键输入

| 文件 | 用途 |
| --- | --- |
| `data/input/ncss/ncss_area_codes_all.json` | 全地区码 JSON |
| `data/input/ncss/ncss_area_codes_all.csv` | 全地区码表格，供城市映射复用 |
| `data/input/ncss/ncss_batch_config_all_areas.json` | 全地区列表扫描配置 |
| `data/input/ncss/ncss_detail_urls_all_areas.csv` | 全国详情页种子 |

地区码由 `src/platforms/ncss/extract_ncss_area_codes.py` 提取。

## 脚本链路

| 阶段 | 脚本 |
| --- | --- |
| 列表抓取 | `src/platforms/ncss/fetch_ncss_jobs.py` |
| 详情页抓取 | `src/platforms/ncss/fetch_pages.py` |
| manifest 重建 | `src/platforms/ncss/rebuild_local_manifest.py` |
| 详情页解析 | `src/platforms/ncss/parse_details.py` |
| 清洗 | `src/clean_jobs.py` |
