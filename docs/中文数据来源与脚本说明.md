# 数据来源与脚本流程

本文说明当前仓库的数据来源、脚本职责和可复现路径。最终论文主线使用 51job 社招招聘文本，NCSS 数据用于地区码、辅助样本和抓取流程验证。

## 数据来源

| 来源 | 仓库角色 | 关键文件 |
| --- | --- | --- |
| 51job 社招 | 论文主样本，提供岗位标题、城市、企业、薪资、招聘正文和发布时间 | `data/processed/51job/51job_social_jobs_clean_with_publish.csv` |
| NCSS | 地区码、全地区抓取样例和辅助招聘样本 | `data/input/ncss/ncss_area_codes_all.csv`、`data/processed/ncss/` |
| 51job 地区树 | 城市映射和 51job 区域口径补充 | `data/input/51job/51job_search_area_tree.json` |
| 竞赛材料和优秀论文 | 论文格式、写作范式和评审材料参考 | `analysis/references/` |

大体量原始抓取和中间表不进入 Git；完整数据包按 `docs/大体量数据获取说明.md` 通过 GitHub Release 附件分发。

## 主流程

1. 采集与清洗 51job 社招数据。
   - 脚本目录：`src/platforms/job51/`
   - 主要配置：`data/input/51job/`
   - 主输入表：`data/processed/51job/51job_social_jobs_clean_with_publish.csv`

2. 构建静态 job-level 主表。
   - 主脚本：`src/analysis_static/a_extraction/build_51job_master_static.py`
   - 收口脚本：`src/analysis_static/a_extraction/finalize_51job_master_static.py`
   - 主分析单元：`city_std_final × job_family_std`
   - 主要输出：`analysis/tables/extraction_outputs/`

3. 生成模型输入和论文表格。
   - 模型输入：`analysis/tables/model_inputs/`
   - 正文表格：`analysis/tables/paper_tables_csv/`
   - 正文图形：`analysis/figures/`

4. 形成论文交付件。
   - Word 与 PDF：`analysis/manuscript/`
   - 公式、修订和写作说明：`analysis/notes/`

## 复现说明

安装依赖后，可从 51job 清洗表恢复静态抽取链：

```powershell
python -m pip install -r requirements.txt
python src/analysis_static/a_extraction/build_51job_master_static.py
python src/analysis_static/a_extraction/finalize_51job_master_static.py
```

如果本地没有大体量数据，请先从对应 GitHub Release 下载数据包，并按数据包内的相对路径解压到仓库根目录。
