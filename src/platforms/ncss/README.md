# NCSS 脚本

本目录保存 NCSS 列表页和详情页采集脚本。

| 文件 | 内容 |
| --- | --- |
| `fetch_ncss_jobs.py` | 列表页采集 |
| `fetch_pages.py` | 详情页 HTML 采集 |
| `parse_details.py` | 详情页解析 |
| `extract_ncss_area_codes.py` | 地区码提取 |
| `build_balanced_ncss_detail_seeds.py` | 均衡详情种子构造 |
| `rebuild_local_manifest.py` | 本地 manifest 重建 |
| `watch_ncss_progress.py` | 抓取进度监控 |

NCSS 的大体量原始和清洗后数据恢复位置见 `data/`。
