# 技能与任务抽取三张表结构

本文档定义的三张表结构：

- `skill_extraction_table.csv`
- `job_skill_long.csv`
- `job_task_long.csv`

---

## 一、skill_extraction_table.csv

表每一行的功能：

```text
一行 = 一条招聘信息 = 一个 job_id
```

主键：

```text
job_id
```

字段结构：

| 字段名 | 类型 | 含义 |
|---|---|---|
| job_id | string | 招聘记录唯一 ID |
| source_job_id | string | 平台原始职位 ID |
| detail_url | string | 职位详情链接 |
| city_std | string | 城市 |
| province_std | string | 省份 |
| publish_time_std | string/date | 发布时间 |
| publish_year | int | 发布年份 |
| publish_quarter | string | 发布季度 |
| publish_month | string | 发布月份 |
| job_title_std | string | 岗位标题 |
| company_name_std | string | 公司名称 |
| job_family | string | 岗位族 |
| salary_avg_month | numeric | 月均薪资 |
| skill_list | string | 技能列表，用 `\|` 分隔 |
| task_list | string | 任务列表，用 `\|` 分隔 |
| skill_category_list | string | 技能大类列表，用 `\|` 分隔 |
| task_category_list | string | 任务大类列表，用 `\|` 分隔 |
| matched_skill_count | int | 命中的技能数量 |
| matched_task_count | int | 命中的任务数量 |
| genai_skill_list | string | GenAI 技能列表，用 `\|` 分隔 |
| digital_skill_list | string | 数字技能列表，用 `\|` 分隔 |
| high_order_skill_list | string | 高阶技能列表，用 `\|` 分隔 |
| routine_skill_list | string | 常规重复技能列表，用 `\|` 分隔 |
| genai_skill_flag | int | 是否命中 GenAI 技能，0/1 |
| digital_skill_flag | int | 是否命中数字技能，0/1 |
| high_order_skill_flag | int | 是否命中高阶技能，0/1 |
| routine_skill_flag | int | 是否命中常规重复技能，0/1 |
| soft_skill_flag | int | 是否命中软技能，0/1 |
| domain_specific_skill_flag | int | 是否命中行业专业技能，0/1 |
| is_ai_native_job | int | 是否 AI 原生岗位，0/1 |
| is_ai_augmented_job | int | 是否 AI 增强岗位，0/1 |
| valid_text_flag | int | 文本是否可用，0/1 |

---

## 二、job_skill_long.csv

表每一行的功能：

```text
一行 = 一条招聘信息命中的一个技能
```

主键建议：

```text
job_id + normalized_skill
```

字段结构：

| 字段名 | 类型 | 含义 |
|---|---|---|
| job_id | string | 招聘记录唯一 ID |
| source_job_id | string | 平台原始职位 ID |
| city_std | string | 城市 |
| province_std | string | 省份 |
| publish_time_std | string/date | 发布时间 |
| publish_year | int | 发布年份 |
| publish_quarter | string | 发布季度 |
| publish_month | string | 发布月份 |
| job_title_std | string | 岗位标题 |
| job_family | string | 岗位族 |
| matched_raw_term | string | 文本中实际命中的原始技能词 |
| normalized_skill | string | 技能名称 |
| skill_category | string | 技能大类 |
| sub_category | string | 技能子类 |
| genai_flag | int | 是否 GenAI 技能，0/1 |
| digital_flag | int | 是否数字技能，0/1 |
| high_order_flag | int | 是否高阶技能，0/1 |
| routine_flag | int | 是否常规重复技能，0/1 |
| soft_skill_flag | int | 是否软技能，0/1 |
| domain_specific_flag | int | 是否行业专业技能，0/1 |
| match_source | string | 匹配来源，如 `term`、`alias`、`pattern`、`llm` |
| match_pattern | string | 命中的词典模式 |

---

## 三、job_task_long.csv

表每一行的功能：

```text
一行 = 一条招聘信息命中的一个任务
```

主键建议：

```text
job_id + normalized_task
```


字段结构：

| 字段名 | 类型 | 含义 |
|---|---|---|
| job_id | string | 招聘记录唯一 ID |
| source_job_id | string | 平台原始职位 ID |
| city_std | string | 城市 |
| province_std | string | 省份 |
| publish_time_std | string/date | 发布时间 |
| publish_year | int | 发布年份 |
| publish_quarter | string | 发布季度 |
| publish_month | string | 发布月份 |
| job_title_std | string | 岗位标题 |
| job_family | string | 岗位族 |
| matched_task_phrase | string | 文本中实际命中的任务短语 |
| normalized_task | string | 任务名称 |
| task_category | string | 任务大类 |
| sub_category | string | 任务子类 |
| core_verb | string | 核心动词 |
| object | string | 任务对象 |
| scenario | string | 应用场景 |
| match_source | string | 匹配来源，如 `pattern`、`llm` |
| match_pattern | string | 命中的任务模式 |
