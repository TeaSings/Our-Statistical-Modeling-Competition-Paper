## 一、当前摘要全文（供对照）

```
[背景与目的] 在全面推进数字中国建设与落实《关于实施就业优先战略促进高质量充分就业的意见》的宏观背景下，缓解结构性就业矛盾、加快数字人才培育已成为实现中国式现代化的重要议题。生成式人工智能（GenAI）作为新一轮人工智能技术演进的重要方向，正通过文本生成、知识处理、数据分析、代码辅助和任务协同等方式，改变企业岗位任务组织与招聘端技能需求结构。本文旨在从招聘需求侧出发，测度 GenAI 显性需求与岗位族大模型暴露度共同作用下，不同城市—岗位族单元的技能结构重塑特征，为因城施策的数字人才培养和就业结构优化提供微观证据。

[数据与方法] 本文基于 51job 在线招聘平台百万级招聘文本，结合规则词典、技能 token 抽取与七维 LLM 文本信号评分，将非结构化招聘信息转化为"城市—岗位族"分析单元。研究基于 Autor 等（2003）的任务模型框架，沿"城市端技术需求—岗位端任务暴露—技能结构重塑"的逻辑主线，构建城市 GenAI 需求强度（）、岗位族 LLM 暴露度（）、技能熵（）以及技能结构重塑指数（）等核心测度指标。在此基础上，采用城市固定效应与岗位族固定效应模型，检验 GenAI 需求强度与岗位暴露度交互项同招聘需求侧技能结构重塑之间的结构性关联，并进一步开展技能复杂度、技能成分分解、异质性和稳健性分析。

[结果与发现] 研究发现：（1）测度特征方面，城市 GenAI 需求强度呈现明显的核心城市集中格局，北京、上海、杭州、深圳、广州等数字经济基础较强的城市在招聘文本中更频繁出现大模型、AIGC、RAG、智能体等显性需求；岗位族 LLM 暴露度则在 AI/算法、数据分析、文案/内容/新媒体、产品和软件/开发/测试等知识密集型岗位中更高。（2）主效应方面，在控制城市固定效应和岗位族固定效应后，城市 GenAI 需求强度与岗位族 LLM 暴露度的交互项与技能结构重塑指数显著正相关，说明当城市端 GenAI 显性需求与岗位端任务暴露同时存在时，相关城市—岗位族单元更容易呈现技能结构调整。（3）机制分解方面，GenAI 交互项主要表现为技能熵上升、GenAI 技能和数字技能占比提高、Routine 技能占比下降；高阶技能占比未呈现显著变化，表明当前阶段的技能重塑更多体现为工具化、数字化和去常规化，而非全面的高阶化升级。（4）异质性方面，技能结构重塑在企业性质和行业属性之间存在差异，民营企业、外资企业以及专业服务、软件与信息技术服务等知识密集型行业中的关联更为明显。

[对策建议] 基于上述发现，本文提出三点建议：一是在城市治理层面，建立"GenAI 需求—岗位暴露—技能短板"联动监测机制，重点关注低 GDI × 高 Exposure 城市的潜在技能转换压力；二是在企业转型层面，推动高暴露岗位的任务再设计，将 AI 辅助、人工审核、业务判断和客户沟通重新组合，形成更清晰的人机协同流程；三是在人才培养层面，从单点数字技能培训转向"GenAI 工具使用—数据分析能力—业务场景理解—协同判断能力"相结合的复合型能力培养体系，以提升劳动者对技术变革的适应能力，助力实现高质量充分就业。

[创新点] 本文将城市端 GenAI 显性需求、岗位族 LLM 暴露度与城市—岗位族技能结构指标整合至同一实证框架，形成基于招聘文本的需求侧技能重塑测度路径。

关键词：生成式人工智能；大模型暴露度；技能结构重塑；招聘文本；双向固定效应
```

```
[数据与方法] 本文基于 51job 平台百万级招聘文本，结合技能 token 抽取与七维 LLM 文本信号评分，构建"城市—岗位族"多维面板数据。研究沿 Autor 等（2003）的任务模型框架，构造城市 GenAI 需求强度（GDI_c）、岗位族 LLM 暴露度（Exposure_g）、技能熵（H_cg）与技能结构重塑指数（SRI_cg）等核心测度指标，并采用城市与岗位族双向固定效应模型，检验 GenAI 需求与岗位暴露交互项同技能结构重塑之间的结构性关联。

[结果与发现] 研究发现：（1）城市 GenAI 需求强度呈现明显的核心城市集中格局，岗位族 LLM 暴露度在 AI/算法、数据分析、内容/新媒体等知识密集型岗位中更高。（2）在控制城市与岗位族固定效应后，GDI_c 与 Exposure_g 的交互项同 SRI_cg 显著正相关，表明城市端显性需求与岗位端任务暴露的叠加是驱动技能重塑的关键条件。（3）机制上，交互项主要表现为技能熵上升、GenAI 技能和数字技能占比提高、Routine 技能占比下降；高阶技能占比未呈现显著变化，表明当前阶段的重塑更多体现为工具化、数字化和去常规化。（4）上述效应在民营企业、外资企业及专业服务、软件与信息技术服务等知识密集型行业中更为明显。

[对策建议] 基于上述发现，本文提出三点建议：在城市层面，建立技术需求与岗位暴露的联动监测机制，重点关注低显性需求、高潜在暴露城市的技能转换压力；在企业层面，推动高暴露岗位的人机协同任务再设计；在人才培养层面，从单点数字技能培训转向 GenAI 工具使用、数据能力与业务判断相结合的复合型能力培养。

[创新点] 本文将城市端 GenAI 显性需求、岗位族 LLM 暴露度与技能结构指标整合至统一实证框架，形成基于招聘文本的需求侧技能重塑测度路径。

关键词：生成式人工智能；大模型暴露度；技能结构重塑；招聘文本；双向固定效应
```
