# 分析与论文材料

本目录保存论文写作和实证分析直接使用的材料。

| 路径 | 内容 |
| --- | --- |
| `manuscript/` | Word 文稿、最终 PDF、AI 使用说明附页和模板 |
| `figures/` | 从最终 Word 文稿中提取的正文图片 |
| `tables/` | 正文表格、模型输入、抽取输出和诊断表 |
| `notes/` | 公式说明、修订记录和写作计划 |
| `references/` | 竞赛材料和往年优秀论文参考 |

生成这些结果所需的大体量全样本数据由 `data/` 记录恢复位置，并通过 GitHub Release 数据包归档。
