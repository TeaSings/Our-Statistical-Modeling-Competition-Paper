# analysis 目录说明

`analysis/` 是论文写作与最终交付资料的主目录。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `manuscript/` | Word 终稿、渲染 PDF、AI 工具使用附页、写作模板 |
| `tables/` | 正文表格、模型输入、城市分类、技能/任务抽取输出 |
| `figures/` | 正文图表 |
| `notes/` | 公式口径、修订说明、摘要/表格精简计划等过程笔记 |
| `references/` | 历年优秀论文、参赛材料和格式规范 |
