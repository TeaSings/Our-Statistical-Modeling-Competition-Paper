# AI 工具使用情况说明——附页

> 本文件作为《全国大学生统计建模大赛参赛作品 AI 工具使用情况表》中"具体用途"和"具体生成内容"两栏的附页补充说明。

---

## 一、使用工具总览

| 工具 | 模型/版本 | 使用方式 |
|------|-----------|----------|
| ChatGPT | GPT-5.5 | 对话式交互，用于文献梳理、语言润色、代码辅助、图表方案讨论 |
| OpenAI Codex | GPT-5.5 | 嵌入代码编辑器，辅助 Python 脚本的代码补全与调试 |
| Gemini | Gemini 3.1 Pro | 对话式交互，用于文献检索、参考文献整理、语法校对 |
| Claude Code | DeepSeek-V4-Pro | 对话式交互，用于文本精简、结构优化、表格调整 |

## 二、具体用途

### 用途 1：文献检索与参考文献整理

- **阶段**：文献综述撰写阶段
- **方式**：使用 ChatGPT、Gemini 等工具检索相关领域文献线索，辅助关键词推荐和题录信息筛选
- **人工工作**：队员根据推荐线索自行检索和阅读原文，独立判断文献相关性和引用价值

### 用途 2：数据爬取与清洗代码辅助

- **阶段**：数据收集与预处理阶段
- **方式**：使用 Codex、ChatGPT 辅助编写招聘网站数据采集脚本的部分代码片段，以及数据清洗流程中字段处理、标准化等环节的代码
- **人工工作**：数据采集方案、反爬策略和数据质量校验规则由队员独立确定；代码经调试修改后集成

### 用途 3：指标计算与模型代码辅助

- **阶段**：数据分析与建模阶段
- **方式**：使用 Codex、ChatGPT 辅助编写部分指标计算函数和回归分析代码框架，以及部分可视化绘图脚本
- **人工工作**：指标定义、计算公式和模型设定由队员独立确定，代码经调试验证后采用

### 用途 4：论文文字优化与结构调整

- **阶段**：论文撰写与修改完善阶段
- **方式**：使用 ChatGPT、Claude Code、Gemini 对论文初稿进行语言润色和语法校对，对部分内容的表述精简和结构优化提出建议
- **人工工作**：队员逐条审核修改建议，独立决定是否采纳；核心论证和结论均由队员原创撰写

### 用途 5：图表设计与可视化辅助

- **阶段**：图表设计与排版阶段
- **方式**：使用 ChatGPT 等工具讨论图表类型选择和可视化方案；使用 Codex 辅助部分绘图代码编写
- **人工工作**：图表的最终设计、数据呈现和配色由队员独立确定

## 三、具体生成内容

### 3.1 数据采集与处理相关代码

- **涉及工具**：Codex、ChatGPT
- **内容概述**：AI 辅助生成了招聘数据爬取脚本的部分代码框架、网页解析逻辑片段，以及数据清洗流程中字段处理、标准化等环节的部分代码。此外，辅助生成了部分指标计算函数和回归分析代码的框架，以及部分数据可视化绘图脚本的代码片段和调试建议。
- **人工处理**：代码整体架构和核心逻辑由队员独立设计和编写，AI 生成的代码片段经逐段审核、调试修改后采用。

### 3.2 论文文字优化

- **涉及工具**：ChatGPT、Claude Code、Gemini
- **内容概述**：AI 对论文初稿进行了语法检查和语言润色建议；对摘要和部分章节中表述冗长之处提出了精简方案；对部分表格的呈现方式提出了优化建议；对部分章节之间的衔接表述提出了调整方案。
- **人工处理**：队员逐条审核所有文字修改建议，仅在不改变原意的前提下选择性采纳；涉及数据、结论和引用的内容均保持原貌；结构调整建议经队员讨论后重新撰写定稿。

### 3.3 参考文献格式整理

- **涉及工具**：Gemini、ChatGPT
- **内容概述**：AI 辅助将参考文献条目按照规范格式进行统一整理，调整字段排列次序和标点格式。
- **人工处理**：队员逐条核查每篇文献的完整性和准确性。

## 四、生成内容占比说明

AI 工具辅助生成的内容主要集中在代码片段辅助、论文文字润色与精简、参考文献格式整理等方面。论文的核心研究内容——研究选题、理论框架、指标体系设计、模型设定、实证结果分析和政策建议提炼——均由队员独立完成。AI 辅助内容占论文及代码工作总量的比例较低，约为 10%–15%。
